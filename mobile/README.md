# CORE Mobile – prototype 0.1.0
Native React Native / Expo development build, not Expo Go. Run `npm install`, `npx expo install --fix`, `npx expo-doctor`, then `npx eas-cli@latest build --platform ios --profile preview` or Android. Apple signing and device registration required for internal iOS distribution. TestFlight requires production build and App Store Connect. Uses existing guest API, native OS speech recognition in foreground (may use OS cloud), Fish PCM converted to WAV for playback. No background wake word, true streaming playback, account login, camera or original 3D orb yet. Dependencies and device behavior require validation. No secrets in app. Speech and chat sent to existing server. Stop on background. Rate limits of existing server apply.
